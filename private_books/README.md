# Private Books Directory

This directory contains PDF files for the Ana Fahim book series.

## Security Notice

This directory is outside the public folder and is protected by:
1. Git ignore rules (see .gitignore)
2. Secure download API routes
3. Token-based authentication

## File Naming Convention

Arabic books:
- ana-fahim-cxr-ar.pdf (Chest X-Ray - الجزء 1)
- ana-fahim-ct-ar.pdf (CT Mastery - الجزء 2)
- ana-fahim-mri-ar.pdf (MRI Mastery - الجزء 3)
- ana-fahim-quality-safety-ar.pdf (Quality & Safety - الجزء 4)
- ana-fahim-radiation-safety-ar.pdf (Radiation Safety - الجزء 5)

English books:
- ana-fahim-cxr-en.pdf (Chest X-Ray - Vol. 1)
- ana-fahim-ct-en.pdf (CT Mastery - Vol. 2)
- ana-fahim-mri-en.pdf (MRI Mastery - Vol. 3)
- ana-fahim-quality-safety-en.pdf (Quality & Safety - Vol. 4)
- ana-fahim-radiation-safety-en.pdf (Radiation Safety - Vol. 5)

## Access Control

Files in this directory are served through:
- `/api/download` endpoint with token verification
- Tokens are generated by `/api/gumroad-webhook` endpoint
- Tokens expire after 24 hours

## Important

- Do not commit these files to git
- Do not make this directory public
- Always use the secure API routes for file access
