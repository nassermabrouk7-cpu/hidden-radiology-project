# Hidden Radiology Logo Assets

This directory contains the official logo assets for Hidden Radiology.

## Required Files

### 1. hr-icon.png
- **Size**: 512x512 pixels (high resolution)
- **Format**: PNG with transparency
- **Description**: Square HR icon with rounded corners for app icon and favicon
- **Usage**: 
  - App icon (`app/icon.png`)
  - Favicon (`public/favicon.png`)
  - Small logo displays

### 2. hr-mark-circular.png
- **Size**: 512x512 pixels (high resolution)
- **Format**: PNG with transparency
- **Description**: Circular glowing HR mark with cyan glow effect
- **Usage**: 
  - Hero section decorative element
  - Store tags
  - Marketing materials

## File Placement Instructions

1. Place your logo files in this directory (`public/logos/`)
2. Ensure files are named exactly as specified above
3. Use high-resolution PNG format with transparency
4. Test logo visibility on both light and dark backgrounds

## Logo Specifications

- **Primary Colors**: Dark Navy (#0a0e1a), Cyan (#06b6d4)
- **Accent Colors**: Silver/Grey gradients
- **Style**: Professional, modern, medical aesthetic
- **Typography**: Bold, sans-serif fonts
- **Effects**: Subtle glow, shadows for depth

## Responsive Guidelines

- **Mobile**: Logo should be clearly visible at 32x32px minimum
- **Tablet**: Optimal at 40x40px
- **Desktop**: High resolution at 48x48px and above
- **Hero**: Large decorative versions at 160x200px
